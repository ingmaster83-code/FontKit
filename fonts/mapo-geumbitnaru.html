폰트 소개

마포금빛나루체는 서울 마포구청이 지역 브랜딩과 일자리 창출을 목표로 제작해 무료 배포하는 공공 서체입니다. 가로획과 세로획의 두께 차이를 줄이고 획 끝을 뭉툭하게 처리해 안정적이고 현대적인 인상을 줍니다. 출처만 표시하면 인쇄물·광고물·온라인 등 상업적 용도로도 자유롭게 사용할 수 있습니다.

추천 활용 분야

  • 관공서·공공기관 문서
  • 지역 브랜딩·홍보물
  • 현수막·포스터
  • 안내 사인물

웹폰트 CSS 사용법

다운로드한 폰트 파일을 프로젝트에 넣고 아래처럼 @font-face로 등록하세요.

@font-face {
  font-family: 'Mapo Geumbitnaru';
  src: url('./mapo-geumbitnaru.woff2') format('woff2');
  font-weight: normal;
  font-display: swap;
}
body { font-family: 'Mapo Geumbitnaru', sans-serif; }

💡 Tips

  • 마포 브랜드 서체는 출처(마포구)를 표시하면 개인·상업 목적 모두 무료로 사용할 수 있습니다.
  • 구글 폰트에는 등록되어 있지 않아 마포서체 공식 사이트(mapofont.or.kr)에서 파일을 내려받아 @font-face로 등록해야 합니다.
  • 폰트 파일 자체를 유료로 재판매하는 것은 금지됩니다.

자주 묻는 질문

마포금빛나루체을(를) 상업적으로 사용해도 되나요?

공공 무료 폰트 (출처 표시 시 상업적 이용 가능, 폰트 파일 재판매 금지) 하에 제공되므로 개인·상업 목적 모두 무료로 사용할 수 있습니다. 폰트 파일 자체를 유료로 재판매하는 것은 허용되지 않습니다.

상업적으로 사용할 때 주의할 점이 있나요?

마포구청 공공 서체이므로 출처(마포구)를 표시해야 하며, 폰트 파일 자체를 유료로 재판매하는 것은 금지됩니다.

파일이 인터넷에 업로드되나요?

아니요. 이 페이지는 폰트 정보와 다운로드 링크만 제공합니다. 파일을 서버로 전송하는 기능은 없습니다.
