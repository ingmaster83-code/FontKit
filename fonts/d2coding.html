폰트 소개

D2Coding은 네이버 개발자 커뮤니티 D2가 만든 한글 코딩 전용 모노스페이스 폰트입니다. 한글과 영문·숫자의 자간이 코드 정렬에 최적화되어 있고, 자소 구분이 뚜렷해 긴 시간 코드를 읽어도 눈이 편합니다. 국내 개발자들 사이에서 코딩폰트 기본값으로 가장 많이 언급되는 폰트 중 하나입니다.

  • API 문서·README

웹폰트 CSS 사용법

/* D2Coding은 Google Fonts에 없어 GitHub에서 폰트 파일을 다운로드해 설치해야 합니다 */
@font-face { font-family: 'D2Coding'; src: url('D2Coding.ttf'); }
code, pre { font-family: 'D2Coding', monospace; }

💡 Tips

  • 라이선스는 OFL로, 개인·상업 이용 모두 무료입니다.
  • Regular / Bold / Ligature(코딩 리거처) 버전을 제공합니다.
  • GitHub Releases 페이지에서 최신 버전 ttf 파일을 받아 설치하세요.

자주 묻는 질문

D2Coding을(를) 상업적으로 사용해도 되나요?

네, OFL (오픈 폰트 라이선스) 하에 개인·상업 목적 모두 무료 사용 가능합니다.

D2Coding과 나눔고딕코딩의 차이는 뭔가요?

둘 다 네이버가 배포하는 한글 코딩 폰트지만, D2Coding은 개발자 커뮤니티 D2에서 별도로 가독성에 더 초점을 맞춰 제작한 폰트로, 코딩 리거처 버전도 제공합니다.

파일이 인터넷에 업로드되나요?

아니요. 이 페이지는 폰트 정보와 다운로드 링크만 제공합니다.
